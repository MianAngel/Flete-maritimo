# Flete Marítimo

Calculadora de flete marítimo y ganancias (versión para PC con Windows).

## Instalar
1. Descarga `FleteMaritimo-Windows-Instalador.zip`.
2. Clic derecho > Extraer todo.
3. Doble clic en `Instalar.bat` (necesita internet; descarga el motor Electron oficial).
4. Si Windows avisa, pulsa "Más información" > "Ejecutar de todas formas".
